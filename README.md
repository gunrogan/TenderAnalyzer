# TenderDigest

Сервис для автоматического анализа тендерной документации с использованием LLM.

Приложение принимает PDF-файл с тендерной документацией, асинхронно обрабатывает его и возвращает структурированную выжимку:

- сумму контракта;
- сроки выполнения;
- ключевые требования к исполнителю;
- предусмотренные штрафы и неустойки.

## Запуск

```bash
# 1. Запустить инфраструктуру (Postgres, Redis, Ollama)
docker compose up -d

# 2. Применить миграции БД
alembic upgrade head

# 3. Запустить воркер очереди в отдельном терминале
celery -A tasks worker --loglevel=info

# 4. Запустить API
uvicorn main:app --reload
```

## Документация API (Swagger)

После запуска документация доступна:

- Swagger UI — http://127.0.0.1:8000/docs
- ReDoc — http://127.0.0.1:8000/redoc
- OpenAPI JSON — http://127.0.0.1:8000/openapi.json

Отключить документацию можно переменной окружения `SWAGGER_ENABLED=false`.
